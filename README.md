✊✋✌️ Rock, Paper, Scissors: Data Visualized
A Python-based Rock, Paper, Scissors game that tracks your gameplay and visualizes the stats using matplotlib. See your win/loss ratio, favorite moves, and the computer's patterns in real-time through interactive charts.

✨ Features
Classic Gameplay: Play against a randomized AI opponent.

Live Analytics: Automatically generates charts (pie charts for win rates, bar graphs for move frequencies) after your session.

Session Tracking: Logs data across multiple rounds to show long-term trends.

🛠️ Tech Stack
-Python 3.x
-Matplotlib

🚀 Quick Start
Bash
# Clone the repository
git clone https://github.com/karanjitsrt-rgb/rps-visualized.git

# Install dependencies
pip install matplotlib

# Run the game
python main.py
